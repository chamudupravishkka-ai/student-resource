## 📂 Project Architecture

The project is divided into two main parts: the static/client-side user interface and the server-side backend.

### 1. 🎨 Frontend View

The frontend is built using Bootstrap 5 and plain HTML/CSS/JS, providing a fully responsive user experience across mobile, tablet, and desktop screens.

* **Key UI Features:** Modern responsive UI, interactive search & filter interfaces, multi-format file cards (PDF, Word, Excel, ZIP), dynamic hero carousel, offcanvas navigation, and complete layout templates.
* **Live Demo:** [View Frontend Live](https://chamudupravishkka-ai.github.io/student-resource/?utm_source=gemini)
